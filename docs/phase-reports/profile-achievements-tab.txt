Profile → Achievements tab (dashboard look) + no brown / gold anywhere
=====================================================================

Summary
- The trainee's Profile → "הישגים" tab is rebuilt in the coach dashboard's achievements look: the pink hero
  (count-up, glowing XP bar, next up, streak tile, latest-unlock tile), filter chips, groups by category
  (dot + name + x/y) with a 3-column badge grid, tilting badge cards, and the achievement modal (flip-in
  medal, confetti, Esc / scrim / ✕, focus in and back).
- Sharing (owner's choice): the board logic moved to @sistem/shared (achievementBoard.ts — both apps use
  it); Medal / BadgeCard / AchievementModal / Confetti / useTilt are copied 1:1 into mobile (no UI package),
  each file marked "MIRROR … change both". The dashboard's AchievementBadge is renamed BadgeCard.
- The medal / card spec is applied to both apps: medal gradient light → color (never darkened), 3px white +
  5px outer ring, count number on count badges, ±8° tilt in a 700px perspective, soft-light sheen, shine
  sweep per hover / press, finger tilt while pressed, spring back; nothing moves with reduced motion.
- Colors: 6 categories kept (נפח stays, owner's choice); גוף ומדידות = #C23BC0 / #F0B3EA (was gold #D9952B).
  No brown, amber, gold or darkened orange token is left. The orange text tone is #C75A00 (--ink-orange).

Known issues / decisions
- #C75A00 text on light orange tints reads 3.7–4.3:1 (AA asks 4.5:1 for small text). It is the owner's
  orange text tone; the contrast audit accepts that one tone down to 3.5:1 (documented in the script). It now
  covers warnings, flags, fat portions and streak dates in both apps.
- White text / icons on the exact fills (#FF7A00, #0094FF …) are under 3:1 in places (the next-up tag, the
  modal's done pill, icon squares): each is marked `contrast-ignore` with the owner rule.
- The dashboard doesn't load Barlow / Karantina (mobile-only fonts, no new dependency), so count numbers on
  its medals use the --font-num fallback; the trainee tab uses the real fonts.
- Mobile badges use the small medal (72px box) to fit three columns at 360px; the dashboard keeps the regular
  one. Dashboard locked cards keep the glass ground on its canvas (--ach-badge-bg), mobile uses soft grey.
- "גוף ומדידות" / "Body & measurements" replaces the old placeholder "גוף" in the dashboard copy too.
- The "הישגים" standalone page (/profile/achievements, Home links) still uses the older list; not in this brief.
- Many of these files already had uncommitted changes from earlier work (profile redesign, the orange-fills
  fix); the commits below include those too — check `git diff` first.
