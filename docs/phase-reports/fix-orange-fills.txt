Fix — workout / zone / fat orange rendered brown
===============================================

Summary
- Cause: fills used the contrast-safe "solid" shades, not the identity colors. Orange → --solid-orange #b85300
  (and color-mix of it with ink ≈ #8f4a1a for text), the zone-3 player ground → #c75a00, the nutrition food
  sheet's selected tab / "added" button → the fat TEXT ink #8a4a00 as a background. No filter, blend or
  overlay was involved.
- Fills now use the exact colors: workouts #FF006E / #7C4DFF / #FF7A00 / #0094FF (+ w5), zones = --color-zone-N,
  nutrition groups = --color-portion-*. The --color-workout-N-solid tokens are gone; new --color-workout-N-text
  is the text tone on a tint / white (orange = #c75a00, text only). Zone -stage tokens = the zone color.
- Week track: today is ink even on a rest day (laneLook returned 'rest' → white lane + dot). Lines on a done /
  today lane are white at 6% (--color-lane-line-on-fill); other lanes keep ink at 5%. done = exact fill,
  planned = 2px ring, missed = soft + dot, rest = hairline (unchanged).

Known issues / decisions
- White text on #FF7A00 is 2.6:1 (WCAG asks ≥ 3:1 large, 4.5:1 small). Kept per the owner's rule; each such
  line carries a `contrast-ignore` note. The owner may want ink text on orange / sky-blue fills instead.
- #c75a00 as small text is 4.3:1 on white and 3.7:1 on #FFEBD6 (AA needs 4.5:1). Used for the workout text tone
  as asked; the nutrition fat TEXT tone stays --ink-orange #8a4a00 (it is text, not a fill, and passes AA).
- Not changed (not workout / zone / fat fills): --solid-orange #b85300 still used by dashboard achievements,
  notifications, the consistency card and the profile links; --color-stat-orange / --color-section-exercises
  #c75a00 are dashboard stat / section TEXT tones (QuickFacts uses stat-orange as a fill — check by eye).
- brightness() filters left as is: they only darken empty soft cells on hover / press (FuelBar, PortionGroupRow,
  FoodSheet), plus the dashboard ConsistencyCard hover (brightens) and the screen transition.
